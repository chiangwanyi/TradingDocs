# 多空力量——从细节中找到强弱的证明

> 本视频是蒋老师直播连麦答疑，主题非常聚焦：**如何从细节（收盘价、影线、解套、缺口、通道位置）中，找到多空双方强弱的证据。** 对话中"张老师/蔡老师"为蒋老师（字幕误识别，统一为蒋老师）；连麦的是 QQ 群里的一位水友。

## 一、从一个头皮单开始：用"订单是否触发"观察多空力量

水友做早盘复盘，开头大幅低开，把低开看作一根大阴线，预期区间、突破失败，想拿一个头皮。

蒋老师点出一个"旁门左道"（水友原话），但其实很有价值：

> 你一开始在这里挂空，这两根非常强是在你考虑当中的，结果**你的空单没有触发，甚至连最低点都没碰到**——那说明**多头力量远比你想象中更强**。

- **多空力量不一定非要从 K 线看，还可以从"你的预期和订单是否触发"中去观察。**

## 二、收盘价：解套与否揭示强弱

蒋老师反复用"收盘价"作为判断多空强弱的标尺：

- 两根大阳线之后，上方一根阴线、又上去、被推下来、很小实体……**收盘价根本没有测到**。
- 如果多头强势，应该给之前在这个收盘价做多的人解套；但**差一跳都没解套**，说明上方卖家比买家多 → 此时不能再想做多。
- 顶部收了三推、连收盘价都测不到 → 应该尝试做空。

## 三、解套离场 = 方向的证据

- 某根长上影线尝试突破通道、去测当天最高点收盘价，那里有人做多，**解套之后价格继续下跌** → 说明解套的人跑了、离场（甚至做空）了 → 这时不能再认为多头大于空头。
- 那根长上影线是"多头推下来"的失败痕迹，50% 处有卖家挂着卖，可以挂单做空（挂 50% 或挂高点都行）。

## 四、止盈要放在"对手期望的位置"

- 做空的止盈，应放在**多头期望的位置**——不是某个低点，而是多头会在这里做多的位置（比如某根 K 线的收盘价，而非被扫掉的下影线低点）。
- 低点可能只是之前做多的人被吃掉、价格往下推了一跳，不代表那里有人继续做多。所以要更细节，放在阴线收盘价，并往上留一跳容错。

## 五、通道的顺势突破与多空力量

- 区间底部 + 通道顺势突破 + 买方看到底部力量多 → 买方更积极买入 → 上涨通道向上突破。
- **顺势突破只有两种走势**：
  1. **终结走势**——往往非常强；
  2. **新趋势的起点**——通常不会走很远。
- 分辨这两种需要经验和对多空力量的分析"要及格"；分辨不了，就最好先当成**终结走势**。

## 六、从影线看强弱

- 空头反弹很弱：反弹的 K 线都带着上影线。
- 一根多头 K 线上涨，用了几根突破下来（123…五根多）→ **空头力量很弱，多头远比空头强**。
- 十字星 = 多空拉锯、价格停滞；前面那根阴线的引线也偏长，说明空头可能没有力量继续往下推进。

## 七、大背景 vs 当前周期（核心总结）

蒋老师用一句话高度概括（这是本期最重要的方法论）：

> **走势"长什么样"是由当前周期决定的；它"要干什么、要到哪儿"是由大背景决定的。**

- 大背景（大区间/宽通道）：决定方向与目标（哪里有人、谁会出手）。
- 当前周期：决定具体的走法与进出场节奏。
- 举例：一个宽通道大背景，高开到某处（没到很伤边缘），开盘两根漂亮阳线，但蒋老师**没做多而做空**——这就是"大背景的作用"；而具体何时入场、跟随后立即往下打，是"当前周期的作用"。

## 八、市场周期冲突 = 趋势减弱

- 市场周期冲突时，大多数时候只代表一个含义：**后面的走势不会很强**（趋势减弱）。其他都是附带。
- 举例：区间突破 + 跟随很好，该追吗？不对——因为**当前周期处于底部**，与大背景冲突，所以大概率是**空头力竭**，后面走宽通道继续下跌，而不是流畅下跌。
- 分辨周期冲突，是做单的重要一环。

## 九、尾盘与随机答疑

- 尾盘几根 K 线不做（太困 / 走势不明）。
- 关于 k28 那段"为什么空比较弱"：蒋老师完整拆解——整体是区间，测试收盘价测试之前多头/空头被套的地方；强势下跌停顿第二段有两段式陷阱嫌疑；测试收盘价擦一下立马收回，说明解套后做空的人有做多意图；处于区间下沿，买家>卖家；中间第二根实心阳线跳空向上，说明收盘做空的立马被套……所以多头更强，顺势突破是新趋势起点。
- 提醒：**形态总会失败，多空力量会验证形态的有效性**，属于锦上添花。

## 总结

本期核心：**多空力量不是玄学，可以从最具体的细节证明——收盘价有没有被解套、订单有没有被触发、影线长短与密度、缺口有没有回补、通道处于区间什么位置。最终落到一句话：当前周期决定"怎么走"，大背景决定"要干嘛"。**
