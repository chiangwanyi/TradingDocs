# 市场周期实例

> 本视频是蒋老师用具体图表对"市场周期"的实战拆解，重点是**如何在多段涨跌的走势里识别区间段/趋势段、如何判断突破的强弱、以及何时该"一段一段看"而不是看大区间**。对话中"蔡老师"为蒋老师（字幕误识别）。

## 一、顺势突破 / 反向突破的两种结果

- **反向突破失败** → 要么终结走势（非常强），要么是新趋势的起点（前面强、中间弱、又继续强）。
- 强势下跌可能是**高潮**，后面强势收盘后能形成区间。

## 二、从回调走法判断区间

- 一根阴线回调砸下来，又立马收回 → 空头没优势、多空平均 → 大概率走区间。
- 连续 K 线在其上 + 前面有高潮嫌疑 → 怀疑是否趋势反转；看突破情况，碰到 EMA 又下来说明上方卖家还在、突破很差 → 大概率仍形成区间。

## 三、"连续性"与"持续性"的反比关系

这是蒋老师反复强调的重要概念：

- **连续的 K 线上涨/下跌，持续性不强**（"只要它是连续性的，就持续性不好"）。
- 良性的上涨应该是**不强也不弱的中性状态**，回调不算大（最多 50% 左右）；若连续上涨/下跌都维持在 50% 之上，就是"过强"，反而不可持续。
- 这也是"拿不住大波段、拿不住趋势"的原因之一：**离场的理由太多了。**

## 四、突破失败的概率判断

- 前面下跌太强 + 接近 0.5 位置 + 出现双顶 → **增加突破失败的概率**。
- 即使进场了，看到双顶就该走（亏也只亏两三个点）。
- 连续阴线下跌可能走第二段，在强势收盘处买/上方挂单买，或干脆不做。

## 五、关键：多段走势后要"一段一段看"

这是本期最核心的结论：

- 当走势**已经走出很多段上涨、很多段下跌**时，**不能再把它当一整个大区间看**。
- 判断标准：**一段大涨 + 一段大跌 = 震荡区间**；当出现"很多段上涨、很多段下跌"时，你知道它是区间，但**不能以整个大区间去做**，要**一段一段看**。
- 区间里 80% 的突破都会失败，所以其中走出的"小趋势"其实都叫**区间段**，要紧盯"第三推会搞事情"。

## 六、复合底部 / 复合顶部

- 一段、两段、三段下跌后，可能在做**复合底部**（三推多了一推，这一推再形成一个底、走双底）。
- 若止损单没被触发，说明空头可能没想象中那么强 → 可能在做复合顶/底。
- 正常的趋势"即使不强势，也不应该出现这种价格行为"，出现这种就是在做复合顶/底。

## 七、三推之后的入场与止损

- 空头第一次入场信号风险较大 → 等二次入场。
- 二次入场（双底/双顶）确定性更高，可入场。
- 区间段做单是**剥头皮**，第三推强势收盘就平。

## 八、从影线看空头失败

- 非常多的下影线 → 空头曾经把价格往下推、但**一直失败** → 阴线跟随很差 → 入场做多（但做反转要多看看，入场信号一定要强势）。

## 九、通道之后接区间

- 通道之后接着是区间；逆势方的强突破可能形成趋势区间起点（或区间已形成）。
- 第一根、第二根、第三根开始尝试反转 → 大概率形成区间。
- 强势下跌但处于区间低位 → 在它没强势突破前，**不该做空**。

## 十、区间的二次入场与一倍

- 区间上沿 + 窄区间突破跟随很好 → 要警惕是假突破/陷阱。
- 一推两推后可能走第三推，强收盘可买，上去取策平仓。
- 三推后第二次入场做空；下来一段两段三段，拿两段或三段（第三段强收盘平）。
- 注意：**没突破大区间，哪来大区间的一倍**——目标看小区间的一倍。

## 十一、结尾观点

- 蒋老师强调：市场周期本身内容不多，**分辨好了其实也就那样**，但很多人学的是"双顶、楔形"这些形态，是半桶水。
- 剩下的核心就是对**多空双方的理解**，掌握好了就没太多东西了。

## 一句话总结

**市场周期实例的要点：连续性越强、持续性越差；多段涨跌后要"一段一段看"、别当大区间做；第三推容易搞事情、强第二推是陷阱；复合顶/底要看止损单有没有被触发来判断对手强弱。**
