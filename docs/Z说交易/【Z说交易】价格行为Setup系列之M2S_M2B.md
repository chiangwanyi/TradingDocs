## 一、视频主旨

本期视频的核心是介绍一个价格行为（Price Action）的入场结构（Setup）：**M2S / M2B**。UP 主强调，任何 Setup 都不是可以脱离背景、孤立使用的「固定公式」，必须结合市场周期与背景判断才能正确运用，否则无法稳定盈利。

---

## 二、M2S / M2B 的定义

根据 UP 主（他常称 Al Brooks 为「阿布爷爷」）梳理的定义：

- **M2B（Move to Bar / 第二次回调到均线附近，多头结构）**：在**上涨趋势**当中，出现的**两段式（two legs）回调**，回调到 **EMA 均线附近**，随后尝试恢复趋势，属于**顺势做多**的结构。
- **M2S（Move to Second / 第二次反弹到均线附近，空头结构）**：在**下跌趋势**当中，出现的**两段式反弹**，反弹到 **EMA 均线附近**，随后尝试恢复下跌趋势，属于**顺势做空**的结构。

### 结构要点

1. 先有一段明确的趋势（上涨或下跌）。
2. 趋势出现第一次回调（第一腿），之后出现第二次回调/反弹（第二腿）。
3. 第二段回调/反弹恰好回踩到 **EMA 均线（如 EMA20）** 附近。
4. 在均线附近出现一根**较好的信号 K 线**（如内包 K、小阳线/小阴线反转 K）。
5. 顺势入场，止损放在第二段回调的低点（做多）或反弹的高点（做空）之外。

## 三、实盘演示（GC 5 分钟图）

UP 主以 5 月 8 日（周五）的黄金期货（GC）5 分钟图为案例，全程演示如何画线、识别背景、捕捉 M2S / M2B。

### 3.1 盘前准备工作

开盘前，UP 主会先画出前一天留下的关键位置：

- **缺口（Gap）**：标注前一天未回补的缺口，判断哪些会被回补、哪些会形成阻力。
- **通道线 / 趋势线**：画出多条可能的通道线，盘中观察机构实际采用哪一条。
- **昨日关键高低点**：昨日尾盘是「从最高点连续向下抛售后进入震荡区间」，并出现小的三角形、末端旗形（楔形）、大的末端旗形等嵌套形态，意味着今天有反转概率。

### 3.2 当日走势解读（核心逻辑链）

1. **开盘跳空低开 → 向下突破失败 → 收在最高的阳线**，随后形成微通道（低点不破前一根 K 线低点）。
2. 出现**一二两腿的反弹**，回补缺口后出现**内包 K 阴线**，此处可尝试做空，同时触发了 **M2S（两段式反弹到均线附近，尝试恢复下跌趋势）**。
3. 空头尝试恢复趋势失败，价格向上反转、突破前高并突破 **EMA20**。此时上方仍有缺口未回补，回补后大概率会遭遇套牢多头的解套抛压。
4. 出现**扩张三角形**、**外包 K 突破**，可尝试做空，预期补掉缺口。
5. 上涨趋势回调后再次触发 **M2B**：一根阴线被强势多头大阳线反包，出现「高一」（higher high），随后又被阴线收回；当再次看到信号 K 时，触发 **M2B**，倾向于从此处恢复趋势做多。

### 3.3 缺口与「阶梯模式」的判断

UP 主特别强调通过**缺口**来判断趋势强弱与市场周期：

- 如果每一个突破缺口**大概率都会被回补**，同时高低点仍在抬高，说明这是**上涨趋势中的弱趋势**，属于市场周期中的**宽通道（Broad Channel）**。（对称地，下跌趋势中每一个向下突破缺口被回补、高低点仍降低，同样属于弱趋势宽通道。）
- 宽通道倾向于**双向交易**，但 UP 主仍主张**顺势交易为主**。
- 「阶梯模式」（阶梯式推进）指缺口都被回补、逆势方能赚到钱的状态，说明趋势「有问题」——顺势方并未真正套住逆势方。

### 3.4 区间交易与 MTR（主要趋势反转）

- 当判断进入**震荡区间**后，UP 主引用「震荡区间 80% 都会突破失败」，在区间上沿高抛、下沿低吸。
- 出现 **MTR（Major Trend Reversal，主要趋势反转）** 的两个条件：
  1. **跌破趋势线**（上涨通道趋势线）；
  2. **制造出 EMA20 均线缺口 K 线**（即一段强势的次级反转，把 K 线放在均线另一侧）。
  当价格再次回测前高时，空头会尝试制造反转波段。
- 结合 **通道线 overshoot（过冲）** 的叠加，可以做空。

## 四、核心观点总结

1. **M2B / M2S 的本质**：趋势中「第二段回调（或反弹）到均线附近」后恢复趋势的顺势入场结构。
   - M2B：上涨趋势中两段式回调到均线附近 → 做多。
   - M2S：下跌趋势中两段式反弹到均线附近 → 做空。
2. **任何 Setup 都必须在背景中运用**：不能孤立地套用「两腿回调」的理论，必须先判断市场周期（突破、窄通道、宽通道、震荡区间）与趋势强度，胜率才有保障。
3. **缺口是判断趋势强弱的核心工具**：缺口是否被回补，直接反映顺势方是否真正「套住」了逆势方，从而判断趋势是强趋势、弱趋势还是已进入震荡区间。
4. **止损逻辑**：止损放在第二段回调/反弹的极值之外，顺势交易。
5. **进阶结构**：MTR（跌破趋势线 + 均线缺口 K 线）是判断趋势可能反转的重要结构。
