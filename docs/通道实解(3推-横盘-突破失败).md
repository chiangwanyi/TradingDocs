# 通道实解(3推-横盘-突破失败)

> 本视频是蒋老师对"通道"的实战拆解，副标题点明三个关键词：**3推、横盘、突破失败**。核心：**通道顶部三推后高位盘整，不要追空；突破失败后跟随差，往往是区间而非趋势。**

## 一、开盘：区间底部 + 通道 + 强支撑

- 今天开盘处于区间底部，然后是通道，这里有强支撑，可以无脑去挂单。
- 挂单后第一根收得很差 → 可以在第一根收盘价就跑；激进一点直接挂在上影线 50%。
- 第二根仍在往上推、收阳线 → 可能走第二腿、第三腿；最好做法是**在上方挂单做空**（昨天尾盘空头比较强，第二段可能造成第三段下跌）。
- 止盈放开盘价/收盘价/低点都行。

## 二、多头力量的确立与加仓

- 一根阴线后跟随很差 → 说明**多头在尝试把价格往上推且成功了**，下方又是买家聚集位置。
- 若后面跟随很好，就确定了多头力量，会带来第二段上涨。
- 蒋老师讲了自己的加仓：第一次在某处、第二次在另一处（因为价格直接往上串）。

## 三、缺口、高潮K线与止盈

- 一个大阳线回补区间内的缺口（之前空头尾盘造成的强缺口），上方必有卖家不断尝试把价格往下推——**这是加仓的原因**。
- 加仓后出现一根**高开 K 线 = 高潮 K 线**，空头的 K 线位就是这里的收盘价/开盘价，直接挂在那里止盈。
- 止盈后反手挂多单，回弹但涨得不快，收盘时平仓。

## 四、"高潮K"后的判断

- 一根大阴线测试后跟十字星，测试高潮 K 的开盘价 → 后面大概率上涨。
- 蒋老师提醒（也是视频里说过的）：**这个位置不要去剥头皮**，但他自己最后还是进了（做空），理由是：不是等收盘才进，而是等它突破该 K 线高点的**一瞬间**试价做空（因为那根 K 线很强）。

## 五、被套与解套的位置

- 区间中上方有被套的人，打平的位置就是这个位置；蒋老师的入场也差不多在这个位置。
- 解套后，本身有一个大阴线支撑，至少还会再往下跌一点，测试某个收盘价（为保险挂在那里）。
- 测到收盘价后，出现对多头非常漂亮的阳线 → 继续上涨概率大于下跌。

## 六、第三段与区间段的离场纪律

- 第二段非常强劲 → 可能走三推（第三段）。
- 既然是**区间段**，第三段应该在**强势收盘时平掉**。
- 更好的入场价位：第一在某处，第二挂下方限价买单（押注突破失败）。

## 七、核心：三推高位盘整，不要追空

这是本期最重要的结论（蒋老师强调"原话"）：

- **三推盘整 / 第三推高位盘整通道，不要去追空、不要做空**，即使看着突破后一根阴线也不要做空，概率很低。
- 正确的判断是：突破之后有一个好的跟随、出现了一根阴线，**还是不要做空**。
- 因为三推 + 区间顶部，空头理论上虽有打压力量，但阴线跟随很差、收在收盘价之上，说明**多头偏强**；测试收盘价后拉出双顶，但整段上涨很强，最大可能是造成**盘整区间**。
- 三推很多时候都是走区间，所以"看到这样的信号就做空"很不理智。

## 八、区间中的买卖盘

- 跟随很差 + 突破收盘价且收在其上 → 多头力量表现。
- 大涨大跌的区间，下方是买盘、上方是卖盘，此处做空"纯脑残"（蒋老师原话的强提醒）。
- 往下假突破后形成三推，出现阳线直接开多；回补缺口（区间特征）时挂单；往上突破看跟随，跟随差就下方挂单跑。

## 九、嵌套三推与末端楔形

- 嵌套三推 + 末端突破 + 没有好的跟随 → 可能是**末端楔形**（末端骑行）。
- 离场的同时可以挂小仓位空单。

## 十、复合顶与突破

- 25/26 位置：26 到区间顶部，若往上继续突破——**跟随好就做多，跟随不好就做空**。
- 复合顶只取决于"这根阴线出来"；阳线后面跟随差就做空（复合顶成立），跟随好就是突破（复合顶失效），不要纠结"复合顶失效"。
- 26 做空的目标先看 24 那个缺口位置；但突破失败时，先看收盘价，而非缺口。

## 十一、多空平衡与区间确认（14-23 段复盘）

蒋老师复盘"14 到 23 那段收盘价"的多空强弱：

- 往上去测收盘价、往下后严格说是空头>多头，但空头跟随很差 → 调整预期。
- 再次测试收盘价 → 多空平衡（空头没跟随、多头不能突破）→ **意识到反转不可能，大概率是区间**。
- 到区间底部，多头应>空头；收十字星（空头尝试往下突破又收回）→ 增加多头力量；后面收阳线、收在收盘价之上 → 多头很强。
- 一根大阴线不代表空头>多头（可能是空头止盈出逃），看后面跟随——跟随又差、空头再次下探失败 → 又增加多头力量。

## 十二、结尾观点

- 蒋老师强调：**不要只看形态，要思考形态为什么发生**，对形态的变化有了解，否则"真成傻逼了"（自嘲式提醒）。
- 双顶/双底拉个测量目标（麦目/MM）就能做，反复进场就是剥头皮。

## 一句话总结

**通道实解的关键：三推高位盘整不追空；突破失败+跟随差=区间而非趋势；用收盘价与跟随判断多空强弱与平衡；别只看形态，要思考形态为何发生。**
