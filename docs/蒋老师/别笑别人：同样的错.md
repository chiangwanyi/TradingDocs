# 别笑别人：同样的错

> 本视频为蒋老师直播连麦，看另一位水友（"黑子"）实时做单，边看边点评纠错。核心：**别人犯的错，往往也是你自己会犯的错，别光顾着笑，要代入思考。** 对话中"姜老师"为蒋老师（字幕误识别，统一为蒋老师）。

## 一、连麦做单的实时纠错（核心片段）

这是一场"看别人做单"的直播，蒋老师逐笔点评水友的操作，重点暴露了几个典型错误：

**1. 该做空时犹豫、不该做多时硬做多**

- 某处明明该逢低做多，水友却想做空；蒋老师反复提醒"这里不是做多吗，你还想做空"。
- 一段强势上涨后，蒋老师提示"这么一大根阳线，肯定还有二段"，但水友仍迟疑。

**2. 尾盘/收盘附近的纪律**

- 水友在某个"十字星"位置想限价进场，蒋老师提醒要"看准了来"。
- 一段走势后水友"怕了、认怂了"平仓，蒋老师指出这跟前面某个位置是同理——**光顾着笑，没学到东西**。

**3. 关键的一次复盘纠错（做空那段）**

水友复盘说自己中间那一段空"太丑了"。蒋老师拆解：

- 背景很确定：**宽通道这里是不是第三推？** 水友当时没意识到。
- 下来之后反弹很强、又立马往上走，更大概率是在做**复合顶部**。
- 该进攻（进场）时不进，因为"前面那一段太强了，强劲到不可持续"——蒋老师强调这个道理讲过很多次，结果还是没想到会走成反转。

**4. 突破的入场时机（第几根进）**

- 水友问某处该不该进，蒋老师：一般来说第 4 根破这个低点，我要么第 3 根进、要么第 5 根进，第 3 根最好。水友"他就慢了"。

**5. 不能继续拿的单子（为什么）**

- 某笔多单，水友问能否继续拿，蒋老师：不能。因为前面是**强突破 + 明显的高潮**，而且对空头来说，这个区间是"最保守的预期"，空头力量会比较强。
- 判断多头强势的依据：**第一点没有测到收盘价**（说明多头强势），但后面跟随收的是"停滞高潮"——停滞之后没有漂亮上涨，就是高潮平了。

## 二、方法论要点（从对话中提炼）

- **看别人做单要代入自己**：别人犯的错 = 你的镜子。水友自己也承认"跟前面那个一样，光顾着笑了，没学到"。
- **第三推 + 强反弹 → 复合顶部**，不要再去追多。
- **高潮不可持续**：强突破/强高潮之后，多头目标只是"最保守预期"，别贪。
- **入场时机**：突破类信号，第 3 根（或第 5 根）进最好，太晚就慢半拍。
- **"停滞高潮"**：停滞之后没有漂亮的上攻，说明动能衰竭，应离场。

## 三、结尾

水友自评"做得一般"，但把前面一位亏钱的兄弟的亏损打了回来。蒋老师总结今天挺好玩的，并提醒直播间的观众——**别人错了别只顾笑，要代入思考，那才是你自己的进步。**
