# 二元决策实战

> 本视频为蒋老师对"二元决策"（趋势/区间 二选一）这一分析框架的完整实战复盘讲解。核心：**先用"大背景"防止犯大错误，再用"当前市场周期"指导具体进出场。** 蒋老师最后强调：他自己做单时很少去想二元决策，这只是简化思考的一个工具。

## 一、二元决策的框架

所谓"二元决策"，就是在每一个时点，先用最简单的方式回答一个问题：**当前是趋势，还是区间？** 然后据此决定方向：

- **趋势中**：顺势为主，回调入场，不轻易逆势。
- **区间中**：上沿做空、下沿做多，剥头皮，不押注突破。

配套的两层判断：

1. **大背景**（大的市场周期）：作用是"防止你去做一些很不好、很错误的操作"，即避免大错误。
2. **当前市场周期**：作用才是"指导你入场的指标"。

## 二、完整复盘推演（开盘起）

**开盘背景**：前面是连续三天的强势上涨（大三推），昨天又是强涨，末端有一个区间，今天跳空高开很高。

- 开盘追多可以，但已靠近"大量买家可能进场的区域"，最多拿个头皮；收得不好就立刻跑。
- 开盘前两根就发现突破、且跟随不错时，**不推荐去追**（容易在上方边缘被打止损）。
- 若判断是通道（上涨趋势+抛售高潮），应找机会做空；若判断是突破，则等强势信号再做空。

**通道上沿做空**：

- 处于宽通道上沿 + 宽通道第三推 + 出现好做空信号 → 挂止损单做空合理。
- 回调没有收阳线，勉强可接受；可在阳线上方挂突破单"押注多头突破失败"，止损往上多挂一点防止针插走双顶。
- 走出双顶后止损可下移。止盈可参考 EMA。

**宽通道中的第三推**：

- 宽通道里第三推容易反转；若第三推又处于下沿，反转概率大增。
- 第二推、第三推非常强时，要在**强势收盘时离场**（做的是历史/复盘，第三推强收盘必须跑）。

**EMA 支撑与追空**：

- 宽通道上涨仍属趋势，EMA 处大概率有支撑，不适合追空；要追空必须等明显阴线确认下跌段强势。

**区间下沿做多**：

- 当价格进入较大区间下沿，应按二元决策找机会做多。长下影线 + 小周期大反转 → 可挂单接。
- 区间中不应押注突破成功，止盈放在上方。

**突破的跟随**：

- 三根 K 线形成突破 → 大概率有第二段 → 直接买。但上方已到一倍高位，止盈别用一倍，放高点收盘价，止损放三根 K 线低点。

**三推离场纪律**：

- 一推、二推、三推，第三推强势收盘就平（或等打止盈）。整体区间上沿 + 空头强信号 K 时，可做空突破，目标看到突破段的 1:1。

**惊喜K线 / 抛售高潮**：

- 惊喜 K 线可能走到 1:1 位置；但结合三段区间段，第三段跟随要好才会继续跌。
- 强下跌后可能形成抛售高潮，持续性强；之后形成通道、三推，可拉一倍/两倍支撑做多（预期只是剥头皮，放 EMA 止盈）。
- 强势下跌 + 回踩 50% → 按二元决策是下跌突破回踩，可挂单做空（止损放上方）。

## 三、关键纪律总结

- **宽通道/区间中，不要持有第三腿的顺势仓位**——第三推强收盘就走。
- **区间下沿做多、上沿做空**，不押突破。
- **大背景防大错，当前周期定进出**。
- 出现不好信号（如三根突破后反向动能强、回补掉三根再停滞）要警惕是否形成区间。

## 结尾观点

蒋老师坦诚：**二元决策就是这么用的，但他个人做单时很少去想这个东西**——它是把"多空力量+市场周期"的复杂分析简化的一个入门工具，而非他真正的做单依据。
