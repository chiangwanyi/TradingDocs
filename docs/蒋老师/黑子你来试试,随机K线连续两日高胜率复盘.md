# 黑子你来试试,随机K线连续两日高胜率复盘

> 本视频是蒋老师的一次"随机 K 线"高胜率复盘演示（两天），目的是回应质疑他"挑K线/造假"的黑粉。核心：**即使是随机抽的 K 线，只要用市场周期 + 多空力量的方法，依然能稳定剥头皮、保持高胜率。** 对话中"蔡老师/陈林"为连麦水友（字幕误识别）。

## 一、开头的背景与用意

- 蒋老师强调这是"随机 K 线"，不是他挑的某一天，全程有录屏可看，回应"打假/小黑子"。
- 他无偿直播、不割韭菜、不收费。

## 二、第一天：跳空高开的处理

- 跳空高开、缺口很大，第一根是非常漂亮的阴线。
- 这里做多、做空都可以；但阴线很大，做空需要逢加仓。
- 第一根大阴线 → 可能继续走第二段 → 仍可在上方挂单做空。
- 止损：这一根 K 线往上一倍的距离。
- 出现折返 → 可能走双顶、往下回补缺口，或走一段 0.5 距离（0.5 就在缺口附近）。
- 因为跳空很大，回补缺口大概率走不到。

## 三、随机复盘中的纪律

- 收得很差 + 处于高位 → 大概率继续下探，可测 EMA。
- 这一段蒋老师尽量少提"多空力量"，避免误导。
- 止损不大，可以再拉一拉；第二段很强势可能再跌一点，后面收阳线就跑。
- 快回撤到 EMA、一倍距离快到 → 挂下方突破单止盈（本质是剥头皮）。
- 立马反向收回去是不好信号 → 直接平仓。
- 平仓后反手做多（差不多一倍位置 + 大高开 + 空头力量没想象中强，因为 EMA 都没回撤到）→ 上方挂单做多，目标回撤收盘价、解放上方做多被套仓位。

## 四、剥头皮的止盈与保本

- 测试收盘价后没收到最高点/收盘价之上 → 空头还想往下推 → 上方挂单做空（剥头皮）。
- 拉一个保本损，或直接止盈，大差不差。

## 五、区间判断与窄区间突破

- 整体走法大概率偏区间 → 不适合往上看很多，往上一点点就好。
- 窄区间出现 → 可先走；不走就拉一拉看是否继续突破。
- 窄区间突破 1:1 往下拉一点。

## 六、按形态复盘（三推）

- 蒋老师在这里切换成"按形态分析"（不讲多空力量）：
  - 一推两推三推，一个大的三推，上涨不漂亮，大涨大跌是区间，尝试突破区间上沿失败 → 做空没问题，目标看开盘价/低点附近。
- 连续下跌 + 大阴线 → 可能是抛售高潮 → 下注做多，跌下来就加仓。
- 但这段很强，虽有空头力竭行为，回调处于上沿，找机会做空（目标不大，用限价单，别用自用单/市价单）。

## 七、利润保护的方法（重点）

蒋老师系统讲了"如何保护利润"，依据"预期大小"：

1. **预期不大**（连续下跌）→ 止损拉得很近，按 K 线高点移动保护利润。
2. **预期较大** → 可先不考虑止盈，扛一波回调再拿更大预期；但前提是**判断要有明确依据**。
3. **讨厌利润回撤** → 用**双顶/双底离场**：挂双顶头的突破单，比较适中，但会丢失一部分大利润。
4. **波段起始不在场** → 无论后面怎么走，都要做紧密的利润保护。

## 八、关于突破的位置与背景

- 突破之后看什么：**要看是什么样的突破、什么位置的突破**——不同位置的突破，涵盖的信息不一样。
- 高开在上半部分 → 大概率卖家把价格往下推；前面不能做多，大概率走区间（一根阳线一根阴线）。
- 做多要等再跌一点，但它不一定能跌，所以先跑（这段确实不好判断）。

## 九、仓位管理（回应质疑）

- 蒋老师回应"2000 回撤、5 万账户"的质疑：当时用一手做（不是总共一手，是"半仓一手"，正常仓位两手）。
- "男孩子不敢加仓就赚不了钱"——但一般只加一次仓，很少加两次。

## 十、多空力量观察的补充

- 某段：判断有人往下买，但没想到是以这种价格下推方式，后面没跟好阴线 → 卖方没想象中强。
- 尝试突破失败、收在中间 → 压住它继续往上。
- 高位盘整很久不碰均线 → 若空头力量强，不该以这种走势盘整；空头每次尝试都很强、但都没碰到均线，多头反扑看着不强却每次都拉上去 → **这是趋势延续（多头更强）的信号**。

## 十一、结尾

- 蒋老师回应"随机 K 线"质疑：不论区间还是趋势，多空差异都有表现，能观测出来。
- 提到原版（Al Brooks 原版课程）只学了几个月就能达到这个水平。
- 再次强调：他无偿直播，希望"好自为之"（对打假者）。

## 总结

**本视频是用"随机 K 线"回应质疑的高胜率复盘：跳空高开、区间、三推、抛售高潮、窄区间突破、利润保护——全程用市场周期+多空力量的方法剥头皮。核心仍是：连续性越强持续性越差、第三推离场、区间高抛低吸、以及按"预期大小"来设定利润保护。**
