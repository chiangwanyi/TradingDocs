# PA不是形态学市场周期最重要【识别重要高低点】

> 本视频为蒋老师直播连麦答疑+复盘切片。核心观点：**价格行为交易中，市场周期（趋势段/区间段）的判断比形态学更重要；形态会失败，真正要关注的是多空双方力量的变化。** 文中"蔡老师"应为"蒋老师"（直播连麦时网友口误/字幕识别错误，统一为蒋老师）。

## 一、核心观点：形态不重要，市场周期与多空力量才重要

- 有网友问：某个三推下跌之后又三推向上，为什么不去预期形成楔形/熊旗？
- 蒋老师回答的核心逻辑：**形态它总是会失败，你要关注的是多空双方的变化，而不是形态怎么变。** 顺势突破的形态多了，但不可能每次都继续按形态的方向走，要看整体状态。
- 这里三推打到某处，**并没有收盘在旗形的收盘价之上**，说明多方强，所以大概率往上，而不是走熊旗。

网友分享自己的学习阶段认知（对话中另一方，非蒋老师）：

> 一开始觉得周期转换很重要，后来又觉得市场情绪、当下的多空力量很重要；多空力量不是信号。现在又觉得周期转换最重要。周期转换能给出一个比较明确的预期。

## 二、市场周期的完整复盘推演

蒋老师对整段图表做了市场周期的连续拆解：

1. 上涨趋势 → 突破 → 走通道 → 顺势突破（顺势突破要么是终结走势，要么是新趋势的起点）。
2. 强势上涨但**后续跟随不好** → 大概率终结走势 → 此处做空，但要知道这是**小反转**，预期会测试通道起点后反弹。
3. 反弹很强 → 做多，上方被套的多头会推动价格往上解套。
4. 上推进入**区间段**，区间段第三推容易"搞事情"（反转），可做空后止盈在低点。
5. 之后弱势盘整通道（末期通道形成盘整），区间突破后可直接拉区间一倍做止盈。
6. 测试通道起点 → 关键：**如果没注意到前低（重要低点），这里不能预期大反转。** 前面一段很强劲，大概率只是小反转，要做高概率的事。

## 三、如何识别重要高低点

这是本视频的实操重点：

- **"强势突破前面的低点，就是重要低点。"**（蒋老师反复强调的原话）
- 常规从突破处数：重要低点可能是第二推的低点，最后一涨是第三推。
- 举例：很多人以某根 K 线（如 248 号）为重要低点，画一条线，认为跌破就反转——但那个位置是**很弱的突破**，真正的强突破在另一处。这个范围可以用相邻几根线都行，不影响判断。
- **大反转的前提：重要低点必须被跌破。** 当它没破时，即使前面连续大阴线下跌，也应预期"不会继续跌多少了"，因为前面有一波大的上涨，形成大反转的概率很低。

## 四、逐K阅读与多周期

- **逐K阅读就是阅读所有信息**，至少掌握 60% 以上就可以做 K 线了。
- 单周期分析不了，就用多周期分析，道理一样。
- 有人喜欢大周期定方向（如日线），再到 3/5 分钟找关键位做单——蒋老师认为这合理、很多人这么做，但他自己很少看大周期。

## 五、答疑要点（碎片）

- **趋势线/通道线怎么画**：顺着走势，发现有一个通道就画出来；发现更高高点或更低低点，连接即可。
- **限价单**：不推荐用限价单（"如果你会限价单，你就不会这么问"），建议市价或突破单为主。
- **止损**：心理问题自己解决（蒋老师调侃"找心理医生"）。
- 强势下跌后做空，至少还会往下再跌一点，至少测试收盘价/开盘价；若又涨上去受不了就离场。

## 总结

本视频最核心的一句话：**形态是表象，市场周期（趋势段/区间段）+ 多空力量才是本质。** 而判断市场周期时，"识别重要高低点"是关键——重要低点是"被强势突破的前低"，只有它被有效跌破，才有资格谈大反转，否则大概率只是小反转。
