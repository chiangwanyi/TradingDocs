# 价格行为系列之如何找到有效的支撑阻力位

> 视频作者：Z 说交易（价格行为学习者，自营交易员）
> 本期视频（UP 主第 2 个视频）系统讲解**支撑与阻力的分类、有效性原理**，并结合 GC（黄金期货）5 月 11 日的行情进行完整复盘。UP 主强调，支撑阻力是学习价格行为的必经之路，掌握了它和形态，就能自由组合出各种 Setup。

---

## 一、视频主旨

支撑阻力是价格行为的基石。本期先讲支撑阻力的分类（静态 / 动态），再讲其**为什么有效（内在逻辑）**，最后通过实盘复盘演示如何叠加支撑阻力找到高胜率的入场点。

---

## 二、支撑阻力的分类

### 2.1 静态支撑阻力（可提前预测、固定不动）

1. **前高前低（波段高低点）**
2. **前高前低的收盘价**：如果有一根好的趋势 K 线，会有顺势方买/卖它的收盘；若第二根 K 线跟随不好，买收盘的人会在入场位挂限价单打平，从而形成阻力。
3. **昨日 / 上周的高低点**
4. **通道线**
5. **50% 回调位**：一段趋势从起涨点到最高点回调到 50% 位置，此时多空盈亏比都是 1:1，但顺势方胜率稍高（约 60%），数学上期望值为正。
6. **趋势起点 / 通道起点**（本质也属于波段高低点）
7. **缺口（Gap）**：UP 主个人交易体系中最重要的支撑阻力位（后续单独开专题讲）。
8. **Gamma（GEX）**：涉及期权的支撑，后续单独讲。

### 2.2 动态支撑阻力（随价格变化而变化）

1. **Measured Move（测量目标位）**
2. **AB = CD**（本质也属于 Measured Move）
3. **均线 VWAP 或 EMA20**：随价格运动不断改变，较难把握。

> 对比：静态支撑阻力容易识别（可提前画出），动态支撑阻力较难把握。

## 三、支撑阻力为什么有效（内在逻辑）

UP 主强调，支撑阻力有效并非「玄学」，而是有明确的内在逻辑——**本质上都是「被套住的一方需要解套/打平离场」**：

1. **前高前低收盘价有效**：因为买/卖收盘的人被套住了，需要打平离场。
2. **前高前低点有效**：因为有人尝试突破；突破失败 → 变成阻力；突破成功 → 支撑阻力转化。
3. **缺口的有效性**：本质上是被套住的一方（多头或空头）在价格回来时打平离场，从而形成支撑/阻力。例如一根光脚阳线（多头从开盘就持续买入）后出现连续阴线抛售，这里的多头被套住，价格回到此处时他们挂空单打平离场。
4. **支撑阻力的叠加**：单一的支撑阻力生效概率较低，但**一个区域里叠加的支撑阻力越多，越容易出现反转或突破**。因此做单应尽量寻找多个理由叠加的位置，胜率才高。

## 四、实盘复盘（GC 5 月 11 日）

### 4.1 盘前判断

- 昨日是大震荡日，今日跳空低开，套住了一些昨日买收盘的多头。
- K1 跳空低开、振幅很大的十字星阴线，预示早盘可能是震荡区间开盘（振幅足够把后续 K 线包含在高低点内）。

### 4.2 关键交易机会（复盘逻辑链）

1. **通道线 + EMA20 叠加做空**：上涨通道（牛旗）中，价格尝试突破趋势线失败，叠加通道线与 EMA20 均线阻力，出现收在最低的内包 K 阴线 → 做空合理（牛旗大概率向下突破）。
2. **高抛低吸**：到区间下半部分倾向做多（但若无好信号 K 则等待），到区间上半部分倾向做空。
3. **多重叠加做空**：昨日缺口 + 通道线 + 前面的通道线，三处叠加，加上 V 型双顶、内包 K 阴线收在最低 → 很好的做空机会，盈亏比至少 2:1。
4. **缺口 + 均线 + M2S 做空**：光脚阳线缺口（非常有效的支撑阻力）+ EMA 均线 + 上一期讲的 M2S 结构（两段式反弹到均线）→ 做空胜率很高。
5. **缺口有效性验证**：某缺口处价格「一个 tick 都不差」地让被套多头打平后下跌，印证缺口=解套位置的逻辑。
6. **MTR 等待**：强下跌后，不急于做多，至少等 MTR（突破下跌通道趋势线、制造均线缺口 K 线、回撤低点）后才考虑做多。
7. **震荡区间内的信号**：内包 K 阳线/十字星后第二根 K 向上突破时做多；双底 + 内包 K 光头阳线做多。
8. **Measured Move 止盈**：突破后把两根 K 线高度翻一倍做测量目标位；突破高点后回调未回补缺口，大概率是测量型缺口（60% 概率到 Measured Move）。

### 4.3 关键结论

- 做单要有**多个支撑阻力位重叠 + 形态叠加**，单一支撑阻力不行。
- 形态很多（三推线型、通道线过冲、失败的失败/二次尝试突破/MTR、多次回补缺口失败、三角形突破、牛旗熊旗、II/IOI 等），与支撑阻力叠加可构建大量交易机会。
- 需等待价格对趋势线/通道线**测试后出现反应**才进场，不能盲目预判支撑阻力会生效。

## 五、核心观点总结

1. **支撑阻力分静态、动态两类**，静态易识别（前高前低、收盘价、昨日高低点、通道线、50% 回调、缺口），动态较难（Measured Move、AB=CD、均线）。
2. **支撑阻力的有效性源于「被套一方解套」的内在逻辑**，缺口是 UP 主体系中最重要的支撑阻力位。
3. **多重支撑阻力叠加 + 形态叠加**是提高胜率的关键，单一支撑阻力胜率低。
4. **左侧交易（限价单）易逆势吃亏，右侧交易（止损单突破进场）胜率更高**。
5. **Measured Move 是做大波段持仓信心的来源**：应倾向期待拿到测量目标位再止盈，否则拿不住。
