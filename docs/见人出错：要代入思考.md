# 见人出错：要代入思考

> 本视频是蒋老师直播看一位水友（被调侃为"小鬼子"，实际是在日本的水友）做单的连麦记录，边看边纠错。核心与《别笑别人：同样的错》一致：**别人犯的错要代入自己思考，别只顾笑。** 对话中"蔡老师"为蒋老师（字幕误识别，统一为蒋老师）。

## 一、核心方法提醒：代入思考

- 蒋老师反复强调：看别人做单，别人错了别光笑，要**代入自己**——"别人犯的错 = 你的镜子"。
- 水友自己也承认"光顾着笑了，没学到"。

## 二、逐笔纠错要点

**1. 下降通道被急速突破后的判断**

- 急速突破下降通道 → 可能是高潮，也可能是新趋势。
- 阴线很强 → 试驾做空可以，接着拿。

**2. 市场周期为什么变成通道了？**

水友问某处"为什么不是变成通道"，蒋老师反问：你前面这一推下跌很强，回调后恢复下降趋势，预期 EMA 处卖家继续出现……单从形态看就是宽通道。顺势突破只有两种走势（新趋势起点 / 终结走势），这里空方力量非常强（多头多次尝试、双顶又失败、突破很差）。

**3. 高潮之后测试买方力量**

- 大下跌 → 高潮 → 再次测试买方/逆势方力量往上打。
- 空头/多头最理想的走势是什么？**区间最重要的标志：突破失败 + 回补缺口。**

**4. 缺口与跟随**

- 区间中唯一/最重要的缺口位置要认清。
- 空头回补缺口、多头测收盘价立马被砸下来、跟随很差 → 该进场时不进（"这第几次了"）。
- 从形态看有大双顶 → 更应该进场。

**5. 买压/卖压与区间突破的关系**

- 区间里要看买压/卖压；任何时候都要看。
- 缺口没被回补 → 增大某一方突破概率；回补非常差 → 也增大某一方突破概率。

**6. 突破时机的纠结**

水友反复"进不进、追不追"，蒋老师总结：

- 顺势宽通道顺势突破的概率比较小，但多头动能在减弱，"他万一假的呢"——假的概率比较低。
- 该追的时候不追，等真突破再追，往往"一波大反弹就给你砸死了"。

**7. 区间里如何做单**

- 区间里用**限价单剥头皮**（强收盘做空/做多）。
- 在低点限价买、高点限价卖；或等真突破跟随好再进。

## 三、结尾

蒋老师一如既往地强调"太菜了""多想想""沉淀一下"。水友自嘲"有点懵"。

## 总结

本期和《别笑别人：同样的错》主题一致：**看别人做单要代入思考**。具体知识点集中在：突破失败+回补缺口=区间的标志；缺口未回补/回补差会增大某一方突破概率；顺势宽通道顺势突破概率小；区间里用限价单剥头皮、看买压卖压。
