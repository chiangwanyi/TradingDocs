# 大小周期冲突的处理

> 本视频是蒋老师对一个具体问题——**大小周期（大背景与当前市场周期）冲突时该如何处理**——的讲解。核心：**冲突时趋势往往减弱，不会流畅；没有冲突时，下跌/上涨才流畅。** 对话中"蔡老师"为蒋老师（字幕误识别）。

## 一、问题来源

蒋老师讲自己当初单纯依照市场周期做单时，经常遇到"特殊情况"：连续上涨没走完第二个人（段），立马下来了。他思考为什么，把图表上所有市场周期都画出来，才发现——**有些地方有冲突**。

## 二、具体案例：大区间突破 vs 通道底部

- 一整个大区间，之后是大区间的突破，突破后按理会往上走、去测试上半部分上 1/3 区域的卖家。
- 但这里没走，而是高点越来越低、又创更低低点，可能走一个通道（假突破后往上推又立马下来，要警惕走通道）。
- 冲突点在于：**大区间突破（应该做空） vs 当前处于通道底部（可能反弹）**——入场在通道底部，就可能反弹，这就"冲突而不冲突"了。

## 三、冲突 → 趋势减弱

- **像这种冲突的情况，往往就是趋势减弱**，后面即便下跌，也不会跌得非常流畅（不会是连续的 K 线下跌）。
- 而**没有市场周期冲突的地方**（如后面某处），下跌就非常流畅。

## 四、隐含通道线（课程知识点）

- 课程里讲过：知道两个高点，可以把两个高点连接起来，然后**克隆一根拉到前面的低点**，这里可能就是一条**隐含通道线**。
- 突破之后又突破，底部位置就可能冲突。

## 五、区间突破 + 好跟随 vs 通道位置

- 区间突破有好的跟随，应该重新入场。
- 但入场在通道的某一半部分，就有可能反弹——这就是冲突所在。

## 六、"突破 + 跟随"提高成功率

- 市场有惯性，突破之后约 80%（字面意思）会继续突破。
- **突破 + 跟随，能提高突破成功的概率**；惯性会倾向于重复市场之前的动作。
- 你需要警惕这个突破就好了。

## 总结

**大小周期冲突的核心结论：当"大背景（大区间）的方向"与"当前市场周期（通道/底部）的位置"矛盾时，趋势会减弱、不会流畅；没有冲突时走势才顺畅。用"隐含通道线"（两高点连线克隆到前低）辅助判断通道位置。突破+跟随能提高成功率。**
