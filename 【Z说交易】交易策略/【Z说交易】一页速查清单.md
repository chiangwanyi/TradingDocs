# 【Z说交易】交易策略 · 一页速查（进场清单）

> 每次想做单前，按顺序走一遍这张清单。理由不够两个，就空仓。

## ① 背景判断（先做，必做）

- [ ] 当前是 **趋势** 还是 **震荡区间**？（二元决策，判断不出 → 不做）
- [ ] 趋势：突破 / 窄通道（强）/ 宽通道（弱）？
- [ ] 震荡：宽 / 中 / 窄（TTR）区间？

**快速判断工具：谁用止损单进场能赚钱？**
- 逆势方止损单赚不到钱 → 强趋势，只能顺势
- 逆势方止损单都能赚钱 → 弱趋势 / 快进震荡
- 双方止损单都不赚钱 + 趋势 K 无跟随 → 一定是震荡区间

## ② 找入场坐标（支撑阻力叠加）

- [ ] 前高前低（波段高低点）
- [ ] 前高前低收盘价
- [ ] 昨日 / 上周高低点
- [ ] 通道线 / 趋势线
- [ ] 50% 回调位
- [ ] 缺口（最重要）
- [ ] Measured Move / AB=CD

> 一个区域里叠加的理由越多，越容易反转或突破。

## ③ 找形态（信号 K）

- [ ] M2B / M2S（两段式回调到均线附近）
- [ ] 二次回补缺口失败
- [ ] 内包 K / 外包 K / Pin Bar / 十字星
- [ ] 牛旗 / 熊旗、双顶双底、三推、楔形、MTR

> 最低要求 = 至少「1 个支撑阻力 + 1 个形态」。

## ④ 入场方向

- [ ] 趋势 → 顺势（M2B 做多 / M2S 做空）
- [ ] 震荡 → 高抛低吸（顶做空、底做多），压住突破失败
- [ ] 右侧交易（止损单突破进场），不做左侧

## ⑤ 止损（知行合一）

- [ ] 止损与入场逻辑一致
- [ ] 看好趋势恢复 → 止损放趋势起点 / 重要波段低点，给足空间
- [ ] 用「反推法」检验：把止损放这里，我真正表达的观点是什么？

## ⑥ 目标位（多画）

- [ ] 引线 AB=CD / 实体 AB=CD
- [ ] 波段高低点 Measured Move（实体 / 引线）
- [ ] 缺口位置（常与目标位叠加）

## ⑦ 持仓与离场

- [ ] 坚定拿到目标位（正期望靠少数大波段）
- [ ] 三种离场：到目标位止盈 / 对手 MTR 后离场 / 等止损
- [ ] 背景变化 → 主动提前离场（不是扛单）

## ⑧ 禁忌自检（出现任一 → 放弃）

- [ ] 在追趋势？
- [ ] 在摸顶 / 抄底？
- [ ] 在压注突破成功？
- [ ] 窄止损与观点矛盾？
- [ ] 想加仓 / 摊平？
- [ ] 有回本心态？
- [ ] 窄通道直接反转？
- [ ] 刚开盘一两根 K 就压注方向？
