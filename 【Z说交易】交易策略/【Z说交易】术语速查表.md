# 【Z说交易】术语速查表

> 整理自「Z 说交易」七期视频中出现的中英文术语与概念，方便快速查阅。按「核心概念 → 缺口 → 形态 → 进场 → 其他」分组。

## 一、核心概念

| 术语 | 含义 |
| --- | --- |
| Price Action | 价格行为（裸 K 交易） |
| 二元决策 | 判断当前是趋势还是震荡区间（唯一基础决策） |
| 背景（Context） | 交易首要考虑的大环境，即趋势/震荡及其周期 |
| 信念感（Conviction） | 对大概率事件的信念（趋势会延续 / 区间会持续） |
| 知行合一 | 止损、持仓预期、趋势恢复预期三者一致 |
| 正期望值 | 数学期望为正，靠少数大波段实现 |

## 二、缺口（体系核心）

| 术语 | 含义 |
| --- | --- |
| Gap | 缺口（跳空 / 套牢位置） |
| 缺口行为（Gap Behavior） | UP 主自创概念：制造/回补/回补实体缺口三要点 |
| Breakout Gap（突破型缺口） | 突破波段高低点 + 跟随后套住逆势方的缺口（最常用） |
| Signal Bar Gap（信号 K 缺口） | 好信号 K 跟随极好后，回到突破位置再次入场的缺口（少用） |
| Measuring Gap（测量缺口） | 未回补、用于测 Measured Move 的缺口 |
| 精准 MM 缺口 | 精准 Measured Move 缺口，最强机构的止盈位置 |
| 最后一个缺口 | 趋势中最后未回补的缺口（引导趋势的机构位置） |
| 实体缺口 | K 线实体之间的缺口 |
| 微缺口 | 相邻 K 线之间的微小缺口 |
| 衰竭缺口（Exhaustion Gap） | 趋势末端出现的缺口 |
| 均线缺口 K 线 | MTR 特征之一：K 线被放到均线另一侧 |

## 三、形态与结构

| 术语 | 含义 |
| --- | --- |
| M2B | 上涨趋势两段式回调到均线附近后恢复（做多结构） |
| M2S | 下跌趋势两段式反弹到均线附近后恢复（做空结构） |
| MTR（Major Trend Reversal） | 主要趋势反转（跌破趋势线 + 均线缺口 K 线） |
| Trading Range | 震荡区间 |
| TTR | 极窄幅震荡（几乎不操作） |
| Tight Channel | 窄通道（强趋势） |
| Broad Channel | 宽通道（弱趋势，双向交易） |
| Expanding Triangle | 扩张三角形（高低点同时外扩） |
| 收敛三角形 | 震荡形态 |
| 末端旗形（Final Flag） | 趋势末端的旗形 |
| 牛旗 / 熊旗（Bull/Bear Flag） | 趋势中的旗形整理 |
| 楔形 / 楔形底（Wedge / Wedge Bottom） | 反转形态 |
| 抛物线楔形（Parabolic Wedge） | 加速后转弱的形态 |
| 三推（Three Pushes） | 趋势末端形态 |
| 双顶 / 双底（DT/DB） | 反转形态 |
| 高潮（Climax） | 趋势末端的加速 |
| 抛售高潮 / 抢购高潮（Sell/Buy Climax） | 趋势末端恐慌抛售 / 抢购 |
| 阶梯式推进 | 缺口被反复回补的弱趋势 |
| 二次回补缺口失败 | 顺势 Setup（多次回补失败暴露强势方） |
| 第二段陷阱 | 震荡区间第二腿诱多/诱空 |

## 四、K 线与进场

| 术语 | 含义 |
| --- | --- |
| Inside Bar（内包 K） | 信号 K 线 |
| Outside Bar（外包 K） | 信号 K 线 |
| II / OI / IIOI | 内包内包 / 外包内包等小级别突破形态 |
| Pin Bar / 锤子 / 流星 | 长影线反转 K 线 |
| Doji（十字星） | 反转 K 线 |
| 光脚阳线 / 光头阴线 | 无下影 / 无上影的 K 线（易形成缺口） |
| Higher/Lower High/Low | 更高/更低高低点（趋势特征） |
| 低一/高一/低二/高二 | 入场形态（回调第 N 腿高低点） |
| Signal Bar（信号 K 线） | 触发入场的 K 线 |
| 止损单（Stop Order） | 突破式挂单（右侧交易） |
| 限价单（Limit Order） | 逆势挂单（左侧交易） |
| 左侧 / 右侧交易 | 预判反转 / 跟随突破 |
| Overshoot（过冲 / 刺穿） | 价格短暂穿越趋势线/通道线 |

## 五、测量与目标位

| 术语 | 含义 |
| --- | --- |
| Measured Move | 测量目标位（等距投影） |
| AB = CD | 等距测量（实体版用收盘价，引线版用高低点） |
| 50% 回调位 | 中位回调（盈亏比 1:1 位置） |
| 前高 / 前低 | 波段高低点（支撑阻力） |
| 前高 / 前低收盘价 | 支撑阻力（被套者打平位置） |
| VWAP | 成交量加权均价（动态支撑阻力） |
| EMA20 | 20 周期指数均线 |
| Gamma（GEX） | 期权相关支撑（未详述） |

## 六、交易执行与心理

| 术语 | 含义 |
| --- | --- |
| Scalp | 短线剥头皮 |
| RR（盈亏比） | 风险报酬比 |
| 加仓（Scaling in） | 逐步增加仓位（新手禁忌） |
| 扛单 | 逆势死扛亏损单 |
| 保本止损 | 移动到成本价的止损 |
| 回本心态 | 亏损后想靠一单回本的心态（不可取） |
| 空仓 | 不持仓（也是主动选择） |
| 用不在乎的钱交易 | Al Brooks 理念（从利益相关方变为观察者） |
