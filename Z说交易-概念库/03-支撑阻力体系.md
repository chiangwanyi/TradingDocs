# 03 · 支撑阻力体系

> 支撑阻力是价格行为的**基石**。掌握了支撑阻力和形态，就能自由组合出各种 Setup。
> 来源：〔支撑阻力〕〔交易逻辑〕〔缺口一〕〔缺口三〕

---

## 1. 支撑阻力的分类

### 1.1 静态支撑阻力（可提前预测、固定不动）

| 序号 | 类型 | 说明 |
| --- | --- | --- |
| 1 | **前高前低（波段高低点）** | 最基本 |
| 2 | **前高前低的收盘价** | 若有一根好趋势 K 线，会有顺势方买/卖它的收盘；若第二根 K 线跟随不好，买收盘的人会在入场位挂限价单打平，形成阻力 |
| 3 | **昨日 / 上周的高低点** | — |
| 4 | **通道线** | — |
| 5 | **50% 回调位** | 从起涨点到最高点回调 50% 位置；多空盈亏比都是 1:1，但顺势方胜率稍高（约 60%），数学期望为正 |
| 6 | **趋势起点 / 通道起点** | 本质也属于波段高低点 |
| 7 | **缺口（Gap）** | Z 体系中**最重要**的支撑阻力位 |
| 8 | **Gamma（GEX）** | 涉及期权的支撑（后续单独讲） |

### 1.2 动态支撑阻力（随价格变化而变化）

1. **Measured Move（测量目标位）**
2. **AB = CD**（本质也属于 Measured Move）
3. **均线 VWAP 或 EMA20**（随价格运动不断改变，较难把握）

> **对比**：静态支撑阻力容易识别（可提前画出）；动态支撑阻力较难把握。〔源:支撑阻力〕

## 2. 支撑阻力为什么有效（内在逻辑）

**核心**：支撑阻力有效并非「玄学」，本质上都是「**被套住的一方需要解套 / 打平离场**」。〔源:支撑阻力〕

1. **前高前低收盘价有效**：买/卖收盘的人被套住了，需要打平离场。
2. **前高前低点有效**：因为有人尝试突破；突破失败 → 变成阻力；突破成功 → 支撑阻力转化。
3. **缺口的有效性**：本质是被套住的一方在价格回来时打平离场。
   - 一根光脚阳线（多头从开盘持续买入）后出现连续阴线抛售，多头被套；价格回到此处时他们挂空单打平离场 → 形成**阻力**。
   - 对称地，一根光头阴线（空头从开盘持续抛售）后出现连续阳线反弹，被套空头在价格回到此处时挂买单打平离场 → 形成**支撑**。
4. **支撑阻力的叠加**：单一支撑阻力生效概率较低；**一个区域里叠加的支撑阻力越多，越容易出现反转或突破**。

---

## 3. 叠加原则（提高胜率的关键）

- 做单要有**多个支撑阻力位重叠 + 形态叠加**，单一支撑阻力不行。〔源:支撑阻力〕
- **进场铁律**：至少要「**一个支撑阻力 + 一个形态**」叠加，才能构成 Setup。〔源:缺口一〕
- Z 的原则：「我进场的理由**没有一个位置是少于两个的**」；震荡区间里支撑阻力、嵌套位置非常多，都可提前画出。〔源:缺口二〕
- 需等待价格对趋势线/通道线**测试后出现反应**才进场，不能盲目预判支撑阻力会生效。〔源:支撑阻力〕

**常见形态清单**（可与支撑阻力叠加组合出大量交易机会）：
三推线型、通道线 overshoot（过冲）、失败的失败 / 二次尝试突破 / MTR、多次回补缺口失败、三角形突破、牛旗/熊旗、II / OI / IIOI 等。〔源:支撑阻力〕〔源:缺口一〕

## 4. 左侧交易 vs 右侧交易

| 类型 | 定义 | 特点 |
| --- | --- | --- |
| **左侧交易** | 没有价格行为证据就去压注某个位置会反转（如直接挂限价单） | 易逆势吃亏，新手常做 |
| **右侧交易** | 用**止损单突破进场**，跟随价格行为证据 | 胜率更高、确定性更强 |

- 价格行为大部分是右侧交易，胜率更高、确定性更强。
- 新手的典型错误：上涨趋势一直摸顶、下跌趋势一直抄底、震荡区间一直压注突破。〔源:支撑阻力〕〔源:缺口一〕

## 5. 下单类型术语

| 术语 | 含义 | 用途 |
| --- | --- | --- |
| **止损单（Stop Order）** | 突破式挂单 | 右侧交易，跟随突破进场 |
| **限价单（Limit Order）** | 逆势挂单 | 左侧交易，压住反转/回补 |
| **盈亏比（RR）** | 风险报酬比 | 评估一笔交易是否值得做 |
| **限价单进场逻辑（震荡区间）** | 在好的趋势 K 顶部/底部（别人挂止损单的位置）挂限价单，甚至更高一点赚 scalp；接近引线/十字星顶底极值时，压住会形成微型双顶/双底 | 〔源:缺口三〕 |
