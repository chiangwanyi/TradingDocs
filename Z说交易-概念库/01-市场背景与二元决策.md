# 01 · 市场背景与二元决策

> 背景（Context）是价格行为中最重要、应放在首位的东西。
> 来源：〔判断趋势〕〔缺口二〕〔缺口一〕〔M2S/M2B〕

---

## 1. 二元决策（第一步且唯一必须做的基础决策）

**定义**：判断当前市场是**趋势**还是**震荡区间**。这是价格行为交易中最基础、最关键的一步。

- 趋势 → 顺势交易；并进一步判断市场周期（突破 / 窄通道 / 宽通道）。
- 震荡 → 高抛低吸、压注突破失败、做反转。
- **判断错误的后果**：在趋势中逆势、在震荡中压注突破，导致「怎么做都不对」，产生「市场在针对我」的错觉。〔源:缺口二〕
- 判断背景错误时，顺势和反转都会做错。〔源:判断趋势〕

**信念感配套（配合二元决策）**：
- 趋势中：相信 **80% 的反转都是小反转**（假反转），趋势大概率延续。
- 震荡中：相信 **80% 的突破都是假突破**，不要压注突破成功。〔源:缺口一〕

---

## 2. 市场周期分级

| 层级 | 分类 | 特征 |
| --- | --- | --- |
| 趋势 | **突破（Breakout）** | 单边快速推进（Spike/急速） |
| 趋势 | **窄通道（Tight Channel，强趋势）** | 顺势方极强，逆势方赚不到钱 |
| 趋势 | **宽通道（Broad Channel，弱趋势）** | 逆势方能赚钱、双向交易，但仍尽量顺势 |
| 震荡 | **震荡区间（Trading Range）** | 高抛低吸，压住突破失败、做反转 |

- 宽通道的典型表现：**每一个突破缺口大概率都会被回补**，同时高低点仍抬高/降低 → 上涨/下跌趋势中的弱趋势。〔源:M2S/M2B〕
- 窄通道、陡峭通道不轻易做反转，需等回调或 MTR。〔源:判断趋势〕

---

## 3. 趋势的定义与五个判断证据

**基本定义**：高点抬高 → 上涨趋势；低点降低 → 下跌趋势。
**注意**：高低点抬高的「上涨趋势」，可能只是震荡区间中的一个上涨波段或几条腿，不能只看波段高低点。〔源:判断趋势〕

### 证据一 · 突破左边的波段高低点
需看趋势有没有**突破左边的波段高低点、有没有制造缺口**，而非只凭「高点抬高」就认定延续。
若同时出现**高点抬高 + 低点降低** → 扩张三角形（本质是震荡区间）。〔源:判断趋势〕

### 证据二 · 缺口是否敞开
| 缺口状态 | 含义 |
| --- | --- |
| 长时间敞开、回调也不回补 | 较强趋势，约 60% 概率去到 Measured Move |
| 回补后再延续 | 逆势方能赚到钱 → 趋势较弱 |
| 连实体缺口都被回补完 | 趋势强度更弱 |

- **关键结论**：逆势方在趋势中能拿到的**极限位置就是回补实体缺口**。若回补完实体缺口后顺势方仍未恢复趋势 → 需警惕反转或进入震荡区间。〔源:判断趋势〕

### 证据三 · 回调的持续时间与幅度
- 回调持续超过 **20 根 K 线**，或回调幅度超过 **60%~70%**、越来越接近趋势起涨点 → 越接近震荡区间的价格行为。
- 好的趋势回调应该**浅**：突破 + 急速 + 通道后的回调通常很浅，可能一个 Higher High 或简单两腿回调就恢复趋势。
- 若回调时间长、需复杂筑底/筑顶才恢复 → 趋势不强，可能演变为震荡区间。〔源:判断趋势〕

### 证据四 · 逆势方的趋势 K 线不应有好的跟随
- 上涨趋势中出现阴线，若跟随仍是好阴线（连续 3~4 根阴线） → 有问题。
- 强趋势中，逆势方的 K 线反而应是**顺势方的入场信号**，很快被套住并制造缺口。
- 若逆势方能制造缺口、出现连续大 K 线 → 需警惕。〔源:判断趋势〕

### 证据五 · 顺势方趋势 K 线的质量
- 应连续、实体饱满、收盘价在高位，持续推进趋势。
- 若跟随差、重叠多，或频繁出现长上下影线、外包 K、内包 K、十字星（铁丝网形态） → 可能演变为末端旗形或 TTR，甚至反转。〔源:判断趋势〕

### 补充证据 · 逆势方能否赚到钱
| 现象 | 结论 |
| --- | --- |
| 逆势方完全赚不到钱（缺口不回补） | 很强趋势 |
| 逆势方能赚钱（回补缺口） | 阶梯模式，趋势较弱 |
| 逆势方的止损单都能赚到钱 | 回调非常深，处于宽通道或倾斜的震荡区间 |

〔源:判断趋势〕

## 4. 震荡区间的六个特征

1. **同时出现上涨和下跌趋势的特征**：如扩张三角形，多空都有好机会，属双向交易（弱趋势/震荡）。
2. **两段式陷阱频繁出现**：两段式突破失败 → 反转 → 再两段式突破失败，来回震荡；第二段甚至非常强，诱使你追突破后被套在顶底。
3. **新高/新低幅度递减**：突破前高时创新高 10 点，下一腿只创 5 点，再下一腿只创 2 点 → 顺势方在前高前低直接止盈，趋势变弱。
4. **逆势方「不该赚钱」的位置反而赚钱**：小概率事件在震荡区间会频繁出现。
5. **缺口无效**：缺口没起支撑阻力作用，被反向实体直接回补 → 要么制造缺口方是大趋势的逆势方，要么处于震荡区间（通常后者居多）。
6. **默认突破失败**：不管尝试多少次突破，都默认它会继续震荡，而非压注突破成功；否则反复亏损。

〔源:判断趋势〕

## 5. 核心难题：趋势转震荡的误判

**问题本质**：震荡并非「一下子」转成，而是有**过渡过程**。你以为还在趋势里（做趋势回调、恢复趋势），实际已身处震荡区间顶部（压注向下突破）或底部（压注向上突破），违反了「震荡区间 80% 突破都是假突破」的法则。〔源:缺口二〕

**判断方法：缺口 + 止损单能否赚钱**

| 观察 | 结论 |
| --- | --- |
| 逆势方的止损单很难赚钱 | 顺势方很强，只能顺势 |
| 逆势方的止损单都能赚钱 | 回调很深、走阶梯模式、弱趋势、双向交易，很快可能进入震荡区间 |
| 双方止损单都赚不到钱、好的趋势 K 线都没有好跟随 | 一定在震荡区间 |

- 缺口（突破型 / 信号 K / 实体缺口的回补或敞开）同样提供背景判断信息。〔源:缺口二〕

---

## 6. 背景惯性

- 今天平开时，可**默认延续昨天的行情**（市场有惯性）。
- 昨天尾盘若是窄幅震荡区间（很多小 K 线、扩张三角形），则今天平开默认延续该震荡状态。〔源:缺口二〕
- 信念感告诉你趋势和震荡区间有**惯性**，不会轻易改变；但当它改变时，你要能反应过来。〔源:缺口二〕
