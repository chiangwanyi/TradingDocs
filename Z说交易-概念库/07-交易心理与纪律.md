# 07 · 交易心理与纪律

> 来源：〔缺口一〕〔缺口二〕〔缺口三〕〔判断趋势〕〔支撑阻力〕

## 1. 信念感（Conviction）

**定义**：对「大概率的事情」的信念。〔源:缺口一〕

| 背景 | 信念内容 |
| --- | --- |
| **趋势中** | 80% 的反转都是小反转，趋势大概率延续，直到出现强劲抛售/抢购高潮或逆势方 MTR。要敢于顺势进场，不要摸顶抄底 |
| **震荡中** | 80% 的突破都是假突破，不要压注突破成功，也不要在区间中间进场 |

- **缺口二版表述**：趋势中只要有 10% 的趋势恢复结构，剩下 90% 靠「趋势会延续」的信念感；震荡中只需 10% 的反转结构，剩下 90% 靠「区间会持续、突破会失败」的信念。〔源:缺口二〕
- 信念感让你在正常回调、区间尝试突破时**不恐慌离场**。

### 信念感 ≠ 固执（≠ 扛单）〔源:缺口二〕
- 当出现连续大 K 线、逆势方制造缺口、套住顺势方、各种证据证明趋势已反转或进入震荡区间时，就不应再固执坚持。
- 信念感只是告诉你趋势和震荡区间有**惯性**；当它改变时，你要能反应过来。

## 2. 「用不在乎的钱交易」（核心心法·裁判比喻）〔源:缺口三〕

**比喻**：你持有多单，就是自己持仓的「裁判」。当出现连续阴线、空头突破时，你本该判空头强势，却因为自己买了多头而「丑化空头」、美化自己，为持仓方向辩护——这时你不是在观察市场，而是在**维护自己的利益**。

- 交易比比赛更残酷：比赛中还有裁判委员会、回访、监管；交易里，你自己就是裁判、是队伍、是委员会、是下注的人，**没有人会纠正你的偏袒**。
- **用不在乎的钱交易，解决的不是「技术判断」问题，而是「身份定义」问题**：让你从「利益相关方」尽可能变成「观察者」，让你在空头强的时候敢于承认空头强、承认自己弱。
- **你不需要更准的判断力，只需要更少的利益关联**。真正做到「亏的时候不心疼、止损不犹豫、更客观」。

---

## 3. 回本心态不可取〔源:缺口三〕

- 亏损后想「回本」，会把回本的想法叠加到下一单，导致心态偏差、盈亏比极度不合理（幻想 3:1、5:1 甚至 10:1 的大单回本）。
- **每一单都应由合理的盈亏比和概率构建**，回本心态会破坏这一切。

---

## 4. 不进行交易的理由（空仓也是一种主动选择）〔源:缺口三〕

1. **背景不明确**（连二元决策都做不出）→ 不交易。
2. **震荡区间中间** → 不交易，耐心等顶底。
3. **左右脑互补**（多空都有缺口敞开、无法判断优势）→ 等待市场给出更多信号。
4. **有明显测量型缺口但离目标位很远** → 不做反转，等它到目标位。
5. **入场理由不够**（少于两个理由）→ 不做，宁可错过。
6. **盈亏比不够好** → 不做，耐心等更好的位置。

## 5. 新手三原则与常见误区

**三个核心原则**：**二元决策 + 右侧交易 + 不加仓**。〔源:缺口一〕

| 误区 | 纠正 |
| --- | --- |
| 少做左侧交易（没有证据就压注反转） | 价格行为大部分是右侧交易（止损单突破进场），胜率更高 |
| 追趋势 | 不要追趋势，耐心等回调；多做旗形 |
| 压注突破（尤其震荡区间顶底） | 少压注突破；震荡区间顶底做反转，只要没大幅突破区间高低点，就要有「会突破失败」的信念 |
| 摸顶抄底 | 上涨趋势一直摸顶、下跌趋势一直抄底 → 典型逆势错误 |
| 刚开盘就压注方向 | 刚开盘一两根 K 线就压注方向/趋势形成或反转是不理智的（除非有大级别分析） |
| 喜欢 K 线少 | 后期反而喜欢 K 线多——需要更多 K 线来验证想法、剖析盘面 |

〔源:缺口一〕〔源:缺口三〕

## 6. 复盘与进步

- **每天大量复盘是进步的关键**（Z 前两年复盘了几千张图）。〔源:缺口二〕
- **大多数人的亏损都发生在震荡区间里**（在区间底部做空、顶部做多、左侧接单）。〔源:缺口二〕
- **判断好背景 + 一点信念感，就能持续赚钱**。〔源:缺口二〕
- 随机回放的训练价值：逐根 K 线验证「方向确定后，找支撑阻力叠加的入场点，理由不够就不做」；震荡区间需要「信念感」——相信区间会持续，高抛低吸，不要害怕顶部的好信号 K，止损放宽一点即可。〔源:判断趋势〕
