## B. 缺口类

| 术语 | 英文 / 别称 | 释义 |
| --- | --- | --- |
| 缺口 | Gap | 价格跳空 / 套牢位置；Z 体系最重要的支撑阻力位 |
| 缺口行为 | Gap Behavior | Z 自创概念，缺口的制造/回补三点 |
| 突破型缺口 | Breakout Gap | 实体突破且有跟随、套住逆势方的缺口（最常用） |
| 信号 K 缺口 | Signal Bar Gap | 好信号 K 的再次入场缺口（使用较少） |
| 实体缺口 | — | 实体之间的缺口 |
| 测量缺口 | Measuring Gap | 用于测量 Measured Move 的未回补缺口 |
| 衰竭缺口 | Exhaustion Gap | 趋势末端出现的缺口 |
| 精准 Measured Move 缺口 | 精准 MM 缺口 | Z 自创概念；对应最强机构的止盈位置 |
| 最后一个缺口 | — | 趋势中最后未回补的缺口；对应引导趋势开始的机构 |
| 微缺口 | — | K 线之间的微小缺口 |
| 均线缺口 K 线 | — | 强势次级反转把 K 线放到均线另一侧；MTR 特征之一 |
| 解套 / 被套 | — | 打平离场 / 被套牢（缺口有效性的本质） |
