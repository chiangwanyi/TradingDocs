# 05 · 入场 Setup 与形态

> 本章汇总所有**可独立引用的入场结构（Setup）与形态**，以及它们的使用前提。
> 来源：〔M2S/M2B〕〔缺口一〕〔缺口二〕〔缺口三〕〔支撑阻力〕〔判断趋势〕

---

## 1. Setup 通则（使用前提）

1. **任何 Setup 都不能脱离背景孤立使用**。必须结合市场周期与背景判断，否则无法稳定盈利。〔源:M2S/M2B〕
2. **进场至少需要两个理由叠加**：「一个支撑阻力 + 一个形态」；理由少于两个则不做，宁可错过。〔源:缺口一〕〔源:缺口三〕
3. **完整决策链**：先判断背景（二元决策）→ 顺势或反转 → 找支撑阻力叠加 → 入场。〔源:判断趋势〕
4. **方向确定后**，再找支撑阻力叠加的入场点；**理由不够就不做**。〔源:判断趋势〕

---

## 2. M2B / M2S（顺势回调入场结构，Setup 系列开篇）

| 结构 | 定义 | 方向 |
| --- | --- | --- |
| **M2B**（Move to Bar） | **上涨趋势**中出现的**两段式（two legs）回调**，回调到 **EMA 均线（如 EMA20）附近**，随后尝试恢复趋势 | 顺势**做多** |
| **M2S**（Move to Second） | **下跌趋势**中出现的**两段式反弹**，反弹到 **EMA 均线附近**，随后尝试恢复下跌趋势 | 顺势**做空** |

**结构要点**：
1. 先有一段明确的趋势（上涨或下跌）。
2. 趋势出现第一次回调（第一腿），之后出现第二次回调/反弹（第二腿）。
3. 第二段回调/反弹恰好回踩到 **EMA 均线（如 EMA20）** 附近。
4. 在均线附近出现一根**较好的信号 K 线**（如内包 K、小阳线/小阴线反转 K）。
5. 顺势入场，止损放在第二段回调的低点（做多）或反弹的高点（做空）之外。

〔源:M2S/M2B〕

---

## 3. 二次回补缺口失败（高效顺势 Setup）

- 缺口下方出现**两次非常接近缺口的双顶**、都未成功回补，出现好的信号 K → **做空机会**。
- 缺口上方出现**两次非常接近缺口的双底**、都未成功回补，出现好的信号 K → **做多机会**。
- **逻辑**：多次尝试回补失败说明被套一方已力竭，反而暴露强势一方趋势，顺势入场可拿到 Measured Move。

〔源:缺口一〕〔源:缺口二〕

---

## 4. 高低一二结构（顺势入场形态）

- **高一 / 高二（Higher High / Higher Low 结构）**：上涨趋势中回调后的入场形态。
- **低一 / 低二（Lower High / Lower Low 结构）**：下跌趋势中反弹后的入场形态。
- 高/低一二是与缺口、支撑阻力叠加时可用的入场结构。

〔源:缺口一〕

---

## 5. 小级别突破形态：II / OI / IIOI

- **II**：内包内包（Inside-Inside）。
- **OI**：外包内包（Outside-Inside）。
- **IIOI**：内包内包外包内包等组合。
- 属小级别突破模式，可与支撑阻力叠加构成 Setup。

〔源:支撑阻力〕〔源:缺口一〕

## 6. 旗形与趋势整理

| 形态 | 含义 |
| --- | --- |
| **牛旗（Bull Flag）** | 上涨趋势中的旗形整理 |
| **熊旗（Bear Flag）** | 下跌趋势中的旗形整理 |
| **末端旗形（Final Flag）** | 趋势末端的旗形，意味着有反转概率 |

- **尽量多做旗形**，最好拿到旗形的 **Measured Move 止盈**，盈亏比常能到 **2~3 倍以上**。〔源:缺口三〕
- 趋势中耐心等回调，在趋势中找回调顺势的机会。〔源:缺口三〕

---

## 7. 反转类形态

| 形态 | 含义 / 使用 |
| --- | --- |
| **楔形（Wedge）** | 反转形态；**楔形底（Wedge Bottom）** 是常见底部反转 |
| **抛物线楔形（Parabolic Wedge）** | 加速后转弱的形态；**高潮后才有反转可能** |
| **三推（Three Pushes）** | 趋势末端形态，常与通道线过冲叠加做反转 |
| **双顶 / 双底（DT / DB）** | 反转形态；**微型双顶/双底**用于小级别反转 |
| **扩张三角形（Expanding Triangle）** | 高低点同时外扩，本质是震荡区间 |
| **收敛三角形** | 震荡形态 |
| **通道线 overshoot（过冲）** | 价格短暂穿越通道线/趋势线 |
| **MTR（Major Trend Reversal）** | 主要趋势反转（条件见 `04-趋势恢复与反转逻辑.md` §4） |

- **窄通道反转要特别小心**：除非特别高潮，否则窄通道直接反转大概率失败，很可能是更大的**第二腿（AB=CD 两腿走势）**；至少需要 MTR 或目标位叠加才考虑。〔源:缺口三〕
- 窄通道、陡峭通道不轻易做反转，等回调或 MTR；抛物线楔形、高潮后才有反转可能。〔源:判断趋势〕

## 8. 震荡区间内的入场方式〔源:缺口三〕

| 区间类型 | 识别 | 入场方式 |
| --- | --- | --- |
| **宽幅区间** | 高低点间距大 | 用**止损单**进场，找顶底好叠加 |
| **中等区间** | — | 可考虑用**限价单**进场（压住突破失败） |
| **窄区间（TTR）** | 重叠极多、上下引线频繁 | **几乎不操作** |

**震荡区间交易四条逻辑**：
1. 发现重叠多、长上下影线、十字星、小 K 线多 → 进入震荡区间，每次突破尝试都压住「会突破失败」。
2. 限价单进场逻辑：在好的趋势 K 顶部/底部（别人挂止损单的位置）挂限价单；接近引线/十字星顶底极值时，压住会形成微型双顶/双底。
3. 盘中可能是趋势 K，收盘却成十字星 → 每根好趋势 K 都应考虑「收盘大概率是十字星、无法制造缺口」。
4. 区间中间进场盈亏比差、胜率低，应耐心等到顶底再做反转。

---

## 9. 第二段陷阱（震荡区间诱多/诱空）〔源:缺口三〕

- 震荡区间典型情况：**第二段（第二腿）非常强**，诱使你追突破，然后把你套在顶底。
- 识别：从区间顶部反转下跌时**没有制造微缺口**，反而跌到区间底部下沿才制造微缺口 → 极大概率是**第二段陷阱（诱空）**，因为该缺口大概率是**衰竭缺口**。
- 配套特征：**新高/新低幅度递减**（见 `01-市场背景与二元决策.md` §4）。

## 10. 入场信号质量的自检技巧

| 技巧 | 结论 |
| --- | --- |
| 入场 K 及其跟随**是否制造微缺口** | 没制造微缺口 → 该入场点**有概率**不是最终拐点 |
| **信号 K 缺口** | 往往出现在趋势顶底，是很好的入场位置 |
| 单腿趋势的**微通道微缺口测量** | 用于测 Measured Move，非常有效 |

〔源:缺口三〕
