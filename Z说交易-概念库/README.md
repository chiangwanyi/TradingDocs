## 二、概念地图（分层）

```
价格行为交易体系（Z说交易）
│
├─ 前提：二元决策 —— 先判断【趋势 还是 震荡】        → 01
│     └─ 市场周期：突破 / 窄通道(强趋势) / 宽通道(弱趋势) / 震荡区间
│
├─ 核心工具：缺口（体系 70% 与缺口相关）              → 02
│     ├─ 缺口本质：被套 → 解套
│     ├─ 分类：突破型 / 信号K / 实体 / 测量 / 衰竭 / 精准MM / 最后一个 / 微缺口
│     └─ 用途：判趋势强弱、判方向、判目标位
│
├─ 判断依据：支撑阻力（静态 / 动态）                  → 03
│     └─ 有效性来源：被套一方解套；叠加越多越有效
│
├─ 逻辑内核：趋势恢复 与 反转（MTR）                   → 04
│     ├─ 交易逻辑三一致：止损 / 预期 / 趋势恢复
│     └─ 拐点本质：逆势方达到目标位、优势衰竭处
│
├─ 执行层：入场 Setup 与形态                          → 05
│     └─ 铁律：背景优先 + 至少「一个支撑阻力 + 一个形态」叠加
│
├─ 风控层：止损 与 目标位管理                          → 06
│
└─ 心法层：信念感 与 交易纪律                          → 07
```
